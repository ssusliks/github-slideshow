# Данные и конфиденциальность

Основа для политики конфиденциальности и анкет магазинов. Перед публикацией текст должен
проверить юрист с учётом стран распространения.

## Что хранит игра

| Данные | Где | Зачем |
|---|---|---|
| Прогресс игры, настройки | на устройстве | работа игры |
| Случайный идентификатор профиля | на устройстве; на сервере при включённом облаке | различать сохранения |
| Прогресс игры | на сервере, если игрок использует облако | перенос между устройствами, восстановление |
| Адрес почты и хеш пароля | на сервере, только если игрок создал аккаунт | вход в аккаунт |
| Идентификатор Google / Apple | на сервере, только если игрок привязал аккаунт | вход в аккаунт |
| Идентификаторы покупок | на сервере | защита от повторного использования чека |
| Журнал технических ошибок | на устройстве | диагностика |

## Что игра не собирает

Имя, контакты, местоположение, фотографии, файлы, список приложений. Пароли в открытом виде
не хранятся.

## Когда данные покидают устройство

- **Облачное сохранение** — когда настроен сервер и есть сеть.
- **Обращение в поддержку** — только когда игрок сам его отправляет. Техническая информация
  (версия игры, тип устройства, сводка прогресса) и журнал ошибок прикладываются по отдельным
  флажкам; журнал по умолчанию выключен.
- **Реклама и покупки** — обрабатываются Google и Apple по их собственным правилам; рекламный
  модуль использует рекламный идентификатор устройства.

## Права игрока

- Удалить локальный профиль: Настройки → «Удалить локальный профиль».
- Удалить аккаунт и все данные на сервере: Настройки → «Удалить облачный аккаунт». Сервер
  удаляет профиль, почту, привязки и сохранения; идентификаторы покупок остаются без связи
  с игроком, чтобы чек нельзя было использовать повторно.
- Играть без аккаунта и без сети.

## Дети

Игра не запрашивает возраст. Если приложение будет ориентировано на детей, рекламу нужно
переключить в режим для детской аудитории (параметры инициализации AdMob).
